name: Admin page redesign scope
description: Scope expectation for future visual redesign work on the reseller/admin panel.
---

When the user asks to redesign admin pages, rebuild each requested route's content hierarchy and responsive page composition, including missing cards and real data states. Do not treat a shared theme or broad CSS overrides as a completed page redesign.

The user explicitly superseded the Hope UI reference and chose an original design from their new brief. Use a cohesive, purpose-built admin identity, with restrained surfaces and motion, readable typography, and no excessive glass or gradients. Preserve Persian RTL and Pulse branding.

**Why:** The user repeatedly clarified that surface styling alone does not resolve missing content and broken layouts, and rejected a previous pastel treatment as too far from the requested reference.

**How to apply:** Use supplied phone/desktop screenshots to identify route-specific gaps, preserve existing data and actions, replace legacy route compositions rather than merely renaming classes, and verify authenticated page rendering when possible.
