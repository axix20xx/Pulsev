The current implementation replaces the configured bootstrap-dns server address with the first usable DNS server from the underlying Android network. The original fallback to 1.1.1.1 is therefore not retained when a physical DNS server is selected.

Implement a reliable bootstrap-resolution strategy compatible with the actual bundled libbox 1.14.3 schema.

Requirements:

* Retain a working fallback when the selected physical DNS server fails.
* Do not assume the first advertised DNS server is reachable.
* Do not perform blocking DNS resolution on the main thread.
* Do not create a circular dependency in which DNS requires the proxy while the proxy requires DNS.
* Resolve hostname-based proxy endpoints before trying to connect to them.
* Support IPv4 and IPv6 DNS addresses.
* Use bounded timeouts and meaningful errors.
* Respect the underlying Android network.
* Do not expose credentials or complete server links in logs.
* Do not blindly modify a valid numeric-IP proxy endpoint.
* Validate the resulting configuration with Libbox.checkConfig().
