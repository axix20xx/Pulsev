1. PRODUCT VISION

PulseVPN is a multi-protocol VPN client supporting:

* V2Box / sing-box configurations.
* OpenVPN.
* WireGuard.
* AmneziaWG.

Users should select a protocol visually, open its dedicated server page, choose automatic or manual connection, and connect with one clear action.

Users must not be exposed to raw VPN configurations, JSON, server URLs, private keys, UUIDs, cryptographic parameters, native engine logs, or technical setup screens during normal usage.

The interface must make complex VPN technology feel simple.

The app must retain its existing backend, login, subscription fetching, native engines, protocol parsers, VPN permission handling, and working connection infrastructure. Rebuild the experience around these capabilities without replacing real connection functionality with mock data.
